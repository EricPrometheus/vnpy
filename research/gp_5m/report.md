## 1. 数据与重采样

| 项 | 值 |
|---|---|
| 原始数据 | 5 个一线币（BTC/ETH/BNB/SOL/XRP）币安**永续（UM）** 1m 线 |
| 区间 | 2023-10-01 ~ 2026-09-30，零缺口（每币 1,578,240 根） |
| 重采样 | polars `group_by_dynamic(every="5m")`，OHLCV 标准聚合（first/max/min/last/sum） |
| 5m 长表 | 1,576,800 行（每币 315,648 根，剔除 288 根量比预热后 315,360 根） |
| 分段 | 训练 2023-10-01~2024-12-31（658,085 行）/ 验证 2025 全年（525,600）/ 测试 2026-01-01~09-21（380,160） |

选永续的理由：费率友好（maker 0.02%/边），本报告全部盈亏数字按该费率口径。

## 2. 特征与标签

基础特征 10 个（全部 5m bar 可算，命名沿用 `factor_common.py` 风格）：

| 占位符 | 名称 | 定义 |
|---|---|---|
| X0 | ret1 | 1 根 5m 收益 `close/ts_delay(close,1)-1` |
| X1 | mom3 | 15m 动量 `close/ts_delay(close,3)-1` |
| X2 | mom12 | 60m 动量 `close/ts_delay(close,12)-1` |
| X3 | amp | 5m 振幅 `(high-low)/close` |
| X4 | body | 实体 `(close-open)/close` |
| X5 | upper_shadow | 上影线 `(high-max(open,close))/close` |
| X6 | lower_shadow | 下影线 `(min(open,close)-low)/close` |
| X7 | vola20 | 20 周期收益波动率 `ts_std(ret1,20)` |
| X8 | volr288 | 量比 `volume/ts_mean(volume,288)`（288 根 = 24 小时） |
| X9 | gap | bar 间隔收益 `open/ts_delay(close,1)-1` |

标签：**下一根 5m bar 收益** `close.shift(-1)/close - 1`（按币分组）。
全段标签均值：训练 +0.00126%/bar、验证 +0.00018%、测试 +0.00005%（牛市漂移递减）。

## 3. 适应度：尾部价差（本次核心创新）

与日线挖矿的本质区别——不再优化"日均截面 Rank IC"（只管整体排序、
不保证两端 extreme 排对），而是直接优化可交易结构：

```
对每个币：按因子值在该币自己的历史上取分位
    前 20%（因子高 -> 做多腿）、后 20%（因子低 -> 做空腿）
    价差 = mean(标签 | 前20%) - mean(标签 | 后20%)
适应度 = 5 个币价差的平均（毛值，不含费用）
```

实现：numpy 向量化——每币**训练段全局分位阈值**一次切片求两腿均值。
启动时自测单次求值耗时：训练段 65.8 万行 **18ms**、全量 150 万行 **56ms**，
远低于 0.5s 硬约束。

**已注明的简化（v1）**：分位阈值取"当前评估段内该币的全局分位"，不做滚动窗口。
后果：
- 训练段有轻微段内前视（阈值用了全段分布）；
- 测试段同口径评估同样用了段内未来分布，**偏宽松**；
- 严格口径（训练段阈值原样套到测试段）已额外报告：毛价差 +0.0023%，
  与宽松口径同量级，结论不变。
- 另一含义：实盘无法逐 bar 知道"当前处于段内前 20%"，需要滚动分位或
  用训练段固定阈值，两者都已覆盖。

## 4. 挖掘配置

gplearn `SymbolicTransformer`：种群 **500** × **10** 代，`n_jobs=1`，
种子 **123**（另加 7 / 2026 两个种子做稳健性），函数集
`["add","sub","mul","div","abs"]`，名人堂 **40**（`n_components` 同为 40，
保证 `transform()` 列与名人堂对齐），锦标赛 20，交叉 0.7 / 子树变异 0.15 /
提升变异 0.05 / 点变异 0.1。复用 `run_gp_mining.py` 的前缀公式解析器
（import 其 `_parse_node` / `_TOKEN_RE`，占位符映射换成 5m 特征定义），
公式翻译全程走标准库 `ast`，无手工拼接。

**与日线配置的一处必要偏离**：parsimony（简约惩罚）由 5e-4 改为 **1e-6**。
原因：5m 尾部价差量级 ~1e-5，比日线 Rank IC（~1e-2）小三个数量级，
沿用 5e-4 时惩罚淹没适应度信号，进化退化为"选最短程序"
（冒烟实验复现：平均树长 17.8 → 3.2，最优公式变成常数平移）。
此为实现层修正，不涉及成败判据。

复检门槛（名人堂 40 → 入选）：验证段毛价差 > 0、训练/验证符号一致、
相关系数 > 0.7 去重，按验证段价差排序。三个种子均只有 **1/40** 通过——
绝大多数公式出样本即翻符号，结构普遍脆弱。

## 5. 主结果（种子 123）

### 5.1 三段尾部价差（最优因子）

| 段 | 毛价差 (/bar) | 扣费后 (/bar) |
|---|---|---|
| 训练 2023-10 ~ 2024-12 | **+0.0083%** | -0.0317% |
| 验证 2025 全年 | **+0.0046%** | -0.0354% |
| 测试 2026-01 ~ 09-21 | **+0.0018%** | **-0.0382%** |

训练 → 验证 → 测试单调衰减（0.83 → 0.46 → 0.18，衰减约 78%），过拟合特征明显。
测试段毛价差甚至低于朴素因子 `volr288`（+0.0040%，见第 6 节）。

两腿拆解（验证段 / 测试段）：

| 腿 | 验证段 | 测试段 |
|---|---|---|
| 做多腿（前 20%） | +0.00141% | +0.00174% |
| 做空腿（后 20%） | -0.00323% | -0.00002% |

验证段的价差主要来自**做空腿**；到测试段做空腿收益归零——
2026 年温和行情里"因子低"不再预示下跌，价差塌掉。

### 5.2 逐月稳定性（2026 年，测试段）

| 月份 | 毛价差 | 净值（扣 0.04%） |
|---|---|---|
| 2026-01 | +0.0004% | -0.0396% |
| 2026-02 | +0.0023% | -0.0377% |
| 2026-03 | +0.0073% | -0.0327% |
| 2026-04 | -0.0005% | -0.0405% |
| 2026-05 | +0.0054% | -0.0346% |
| 2026-06 | +0.0011% | -0.0389% |
| 2026-07 | -0.0050% | -0.0450% |
| 2026-08 | +0.0060% | -0.0340% |
| 2026-09(至 21 日) | +0.0047% | -0.0353% |

毛价差 7/9 个月为正（方向有一致性），但**净值 0/9**——最好的月份
（3 月 +0.0073%）也只有费的 1/5。固定阈值严格口径：测试段毛 +0.0023% /
净 -0.0377%，与宽松口径同结论。

### 5.3 最优公式

gplearn 原式：

```
sub(sub(X6, sub(sub(X5, add(abs(X1), X4)), abs(add(X6, X0)))),
    sub(sub(abs(X5), add(abs(X1), X4)), abs(add(X6, X0))))
```

翻译为特征定义文本：

```
(min(open,close)-low)/close
  - ((high-max(open,close))/close - (abs(mom3)+body) - abs(lower_shadow+ret1))
  - (abs(upper_shadow) - (abs(mom3)+body) - abs(lower_shadow+ret1))
```

手工化简（因 upper_shadow ≥ 0 恒成立，数学上完全等价）：

```
lower_shadow - 2*upper_shadow + 2*(abs(mom3) + body) + 2*abs(lower_shadow + ret1)
```

直觉解读：**下影线长、实体大、短动量强 → 下一根偏涨；上影线长 → 偏跌**。
方向符合微观结构反转常识，但边际太薄。

## 6. 稳健性与校准

### 6.1 多种子（同配置，仅换种子）

| 种子 | 训练 | 验证 | 测试(毛) | 测试(净) | 逐月净>0 | 公式 |
|---|---|---|---|---|---|---|
| 123 | +0.0083% | +0.0046% | +0.0018% | -0.0382% | 0/9 | 下影线-上影线+动量组合（见上） |
| 7 | +0.0069% | +0.0039% | +0.0013% | -0.0387% | 0/9 | `(mom3+0.009)*ret1` |
| 2026 | +0.0072% | +0.0009% | -0.0006% | -0.0406% | 0/9 | `abs(lower_shadow+body)-upper_shadow` |

三个种子挖出**三个不同公式**，只有量级一致（训练 ~0.007%、测试 ≤0.002%）——
没有稳定的公共结构，是"弱信号 + 过拟合噪声"的典型形态。

### 6.2 朴素因子天花板校准（判断"是不是 GP 没挖好"）

用 10 个基础特征及其反转直接算尾部价差：

| 因子 | 训练 | 验证 | 测试 |
|---|---|---|---|
| amp（振幅） | +0.0046% | -0.0002% | +0.0024% |
| vola20（波动） | +0.0040% | +0.0016% | +0.0008% |
| volr288（量比） | +0.0030% | -0.0001% | +0.0040% |
| lower_shadow | +0.0034% | -0.0016% | -0.0017% |
| ret1（动量） | +0.0011% | +0.0000% | +0.0005% |
| neg_ret1（反转） | -0.0011% | -0.0000% | -0.0005% |

**所有朴素因子的毛价差天花板都在 ±0.005%/bar 量级，全部深度负净值。**
GP 最优在训练段（0.0083%）约为最优朴素因子的 2 倍，说明 GP 确实找到了
增量信息；但出样本后衰减回朴素因子水平之下。**瓶颈是目标本身的量级
（5m 尾部价差天然只有万分之几），不是挖掘算法**。

### 6.3 打平需要什么条件

- 按"每根 bar 双腿全额换手"：需要毛价差 > 0.04%，即再挖出 **22 倍**的信号；
- 或费率降到 0.0009%/边，比零售 maker（0.02%）低 **22 倍**，现实费率体系内不可达；
- 或把换手降到约 1/22（平均持仓 ~110 分钟）——信号是逐 bar 分位定义的，
  持仓延续逻辑（v2）理论上可做，但那是另一个策略，且测试段毛价差本身
  也只剩 0.002%/bar，容错空间极小。

## 7. 已知简化与口径声明

1. **段内全局分位阈值**（无滚动窗口）：训练段轻微前视、测试段偏宽松；
   严格口径（训练段固定阈值套测试）已报告，结论不变。
2. **费用口径刻意保守**：假设每根 bar 双腿全额换手（往返 0.04%/bar）。
   实际持仓延续会摊薄费用，但如 6.3 所述，摊薄 22 倍才打平，救不了。
3. 未含资金费率（永续 8h 结算）、滑点按 0（maker 挂单假设）、无借贷成本。
4. 9 月为 partial month（至 09-21）。
5. gplearn 逐行求值感知不了"同一时刻跨币比大小"；本适应度按币做
   **时间序列**分位（每币自己的历史前/后 20%），5 币平均——只有 5 个币时
   截面分位无意义（前 20% = 1 个币），该设计是定义使然而非妥协。
